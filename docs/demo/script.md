# Demo video script

About 3 minutes. Demo input: **package 01, Northgate Infrastructure Fund III** (fictional, law firm Hartwell & Crane LLP; [answer key](../../samples/packages/01-northgate-infrastructure-iii/answer-key.md)).
Live site: https://preflight-legal-reviewer.giathaowork.workers.dev

**Before recording:** use a normal browser at 1440 px, pass the Turnstile check once, set the sidebar switch to **No AI**, and rehearse once to see the real gate count and Changes count.

| Time | On screen | Narration |
|---|---|---|
| 0:00-0:20 | Empty app | "Before Anduin digitizes a fund's subscription document, an analyst reads it for anything that would break the form. Preflight does that pass first, and shows its evidence." |
| 0:20-0:50 | **Demo packages → Northgate Capital III**. In the table: 01 **To digitize**, 04 **Baseline**, tick **Confirmed**, version `v1`, **Run checks**. | "A fund arrives as a package. Preflight proposes each file's type and role. Two files are both sub agreements, so it asks me instead of guessing." |
| 0:50-1:30 | Findings: click the Annex F row (the document scrolls to it). **Ask counsel**. On the placeholder row: **Close issue** → reason → Save. | "Every finding is a rule and quotes the text. Section 9.1 says 'complete Annex F', and no Annex F exists, so the gate is blocked. Two buttons: ask counsel, or close it with a reason, which is remembered for this law firm." |
| 1:30-2:05 | Segment **Changes** (vs Fund II): point at an impact line and an owner chip. | "Against last year's fund there are hundreds of raw edits. Preflight hides the cosmetic ones and shows the few that change the form, who they affect, and who must confirm each." |
| 2:05-2:35 | **Questions**: tabs Counsel / GP / Fund admin, group **For the GP** (7 missing documents), **Export request DOCX**. | "Questions go to whoever can answer them. The GP gets one request listing every missing document, each with the sentence that mentions it." |
| 2:35-3:00 | Click the gate pill. | "The gate stays blocked until counsel answers. Catch it once in the template, not in every investor's form. Thank you." |

**Do not claim on camera:**
- Package 01 shows 9 change rows, not the answer key's 7. Say "a handful", or the number you see.
- The "Eligible Transferee Certificate" and the $2.5M vs $5M minimum are still missed.
- The live gate count for this package is unverified; say what you see.
